## 🎓 Student Course Manager

Консольное приложение для управления студентами, курсами и записями.

### Возможности:
- CRUD-операции со студентами, курсами и записями
- Сохранение и загрузка данных в формате JSON
- Отчёты (JOIN, GROUP BY) через LINQ

### Технологии:
- C# (.NET)
- System.Text.Json (сериализация)
- LINQ
- File I/O
